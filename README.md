# SetIP_Mac - macOS IP 快速切换工具

双击 `SetIP.app` 即可运行：打开的是 App 自带的原生面板窗口（**不再调用系统终端**）。窗口一屏分区布局（默认 980×560，可缩放，无滚动条），采用深色主题（对标 WorkBuddy），分三块——顶部蓝色渐变标题栏（左侧标识、右侧「⌂ 主界面」按钮和版本号）、中间深灰圆角卡片输出区（网卡列表与当前配置左右并排）、底部圆角输入框。内容以 UI 卡片渲染：网卡是带序号徽章的列表、活动网卡高亮、配置是彩色标签 + 等宽值、执行结果是「已生效/未生效」徽章。文字全部采用高对比配色（对比度 ≥ 4.5:1），清晰易读。每按回车清屏一次，只显示当前步骤。`q` 退出后窗口关闭、Dock 图标也随之消失。

**选择既可输入也可上下选择**：在选网卡、应用配置、代理 PAC 这几类列表界面，既可以直接输入序号回车，也可以按 `↑` / `↓` 方向键在选项间移动——选中项会有 `▸` 箭头和淡蓝底高亮，其值自动填入输入框，再按回车确认。首次按 `↓` 从第一项开始、`↑` 从最后一项开始，到头循环；一旦手动改输入框内容就取消高亮、以输入为准。网卡界面的 `c/h/p/o`、主菜单的 `5-8` 等非列表项仍需直接输入。

**一键返回主界面**：在任意步骤（选网卡、编辑配置、执行结果）都能立刻回到主界面——点顶部「⌂ 主界面」按钮，或按 `Esc` / `⌘R`，或在输入框输入 `m`。返回时会重新读取磁盘配置，丢弃未保存的编辑中途状态。

> Windows 版在 [`windows/`](windows/) 目录，功能与菜单完全一致（含设置菜单、配置内置），见 [windows/README.md](windows/README.md)。Windows 是控制台程序，仍用 ANSI 彩色文本（没有原生卡片窗口）。

## 功能

- 1、公司 —— 按配置中的 `company` 段设置静态 IP
- 2、家里 —— 按配置中的 `home` 段设置静态 IP
- 3、DHCP —— 自动获取 IP，并清除手动 DNS / 搜索域
- 4、代理 PAC —— 子选项 WAN-PROXY / LAN-PROXY / 关闭代理
- 5、修改公司配置 / 6、修改家里配置 / 7、修改 PAC 代理链接 / 8、打开配置文件 —— 都在主菜单，直接改，保存即生效

每次设置后回读系统实际配置并核对，只用一行显示结果：全部生效时列出实际值，不一致时只列出异常项。每一步不再打印大段中间信息。

**每按一次回车进入下一步，窗口都会清屏，只显示当前步骤的内容**，上一步的输出不再保留。看完本步结果后按回车进入下一步。

选网卡界面用卡片列出网卡和当前配置。**活动网卡自动识别、高亮并标「当前活动」，直接回车选中；要换网卡输入序号，或按 ↑/↓ 方向键选择后回车。**

```

当前配置
[公司]  10.91.140.5/255.255.254.0  网关 10.91.140.1
[家里]  192.168.168.102/255.255.255.0  网关 192.168.168.1
[PAC]   WAN ...  LAN ...
c 改公司 · h 改家里 · p 改 PAC · o 配置文件 · m 主界面 · q 退出

```

看完结果按回车，界面清屏后回到应用菜单。改完配置也会自动保存并立即生效。

## 输出配色

原生 App 窗口用卡片 / 徽章和主题色渲染，不再依赖终端 ANSI：

| 元素 | 样式 |
|------|------|
| 标题 / 菜单编号 | 蓝色主题徽章 |
| 活动网卡 | 绿色高亮 + 「当前活动」标签 |
| 公司 / 家里 / PAC | 绿 / 青 / 紫标签，值为等宽字 |
| 已生效 | 绿底徽章 [已生效] |
| 未生效 | 红底徽章 [未生效] + 异常详情 |
| 警告 | 琥珀色 ⚠ |
| 次要信息 / 输入提示 | 灰色小字 |

Windows 控制台版仍用 ANSI 颜色区分状态（绿 ✓ / 红 ✗ / 黄 ⚠ / 青标题 / 灰标签），可用 `SETIP_COLOR=never` 关闭、`always` 强制开启。

## 配置文件

配置文件**打包在 app 内部**：`SetIP.app/Contents/Resources/config.yaml`

- 优先使用包内配置（配置跟着 app 走，复制/移动 app 不会丢配置）
- 包内不可写时自动回退到 `~/.setip/config.yaml`
- 重新打包 App 时会沿用包内已修改的配置，不会用模板覆盖（见 `mac/build_app.sh`）
- 修改方式：程序里选 `5、设置`，或用文本编辑器打开配置文件（设置菜单第 4 项）

模板格式：

```yaml
company:
  ip: 10.91.140.5
  netmask: 255.255.254.0
  gateway: 10.91.140.1
  dns:
    - 10.91.140.1
  search_domains: []      # 可留空

home:
  ip: 192.168.168.3
  netmask: 255.255.255.0
  gateway: 192.168.168.1
  dns:
    - 114.114.114.114
    - 8.8.8.8
  search_domains: []

proxy:                  # PAC 自动代理链接（WAN / LAN 地址不同）
  wan: https://www.wlgo.cc/st/go.js
  lan: https://www.wlgo.cc/st/golan.js
```

## 修改配置后重新打包 App（仅开发时需要）

```shell
python3 -m venv .build-venv
.build-venv/bin/pip install pyyaml pyinstaller
.build-venv/bin/pyinstaller --onefile --name SetIP --icon icon.icns --clean -y main.py
./mac/build_app.sh     # 编译原生宿主窗口 + 组装 SetIP.app + 签名
# dist/SetIP 即为可执行文件；完整 app 在 SetIP.app（见 mac/SetIPHost.m）
```

## 注意

- 修改网络设置需要管理员权限。绝大多数情况下 `networksetup` 会直接生效；若提示权限不足，在终端里用 `sudo SetIP.app/Contents/MacOS/SetIP-bin` 手动运行。
- 旧版 `IPSet.sh` 与 click 依赖已不再需要。
